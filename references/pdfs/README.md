# PDF Sources

Bu klasor, `yeni.md` icinden tiklanabilir verilmek istenen PDF kaynaklari icin tutulur.

Kullanim:
- `yeni.md` icinden link verirken `./references/pdfs/dosya_adi.pdf` kalibini kullan.
- `references/used_sources.md` icinden link verirken `./pdfs/dosya_adi.pdf` kalibini kullan.
- Dosya adlarini degistireceksen, hem `yeni.md` hem `used_sources.md` icindeki linkleri birlikte guncelle.

Ornek:
- `[Kaynak PDF](./references/pdfs/G32_lm5146-q1.pdf)`
- `[Datasheet](./pdfs/G32_lm5146-q1.pdf)`
